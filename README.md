# AI Provider OpenAI

Connect Backdrop’s AI features to OpenAI models using an OpenAI API key. Use it for chat, image generation, search embeddings, speech generation and transcription, or content moderation. Choose a model that supports the task.

## Requirements

Backdrop CMS 1.x, PHP 8.2 or later, and the AI module, plus the Key module.

## Installation

1. Install and enable this module using the official [Backdrop CMS instructions](https://backdropcms.org/user-guide/modules).
2. Open **AI settings** at `admin/config/ai/settings` and enable the provider. Select the service credential you saved with the Key module.
3. Choose a model for each operation you plan to use.

Read the [module wiki](https://github.com/backdrop-contrib/ai_provider_openai/wiki) for setup details, supported operations, and troubleshooting.
